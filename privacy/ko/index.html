본 앱은 해외 전시회·출장에서 업체 방문 기록(질문, 답변 녹음, 사진, 메모)을 돕는 도구입니다. 계정 가입이 없으며, 이름·이메일·전화번호 등 이용자를 식별하는 정보를 수집하지 않습니다. 모든 기록은 기본적으로 이용자의 기기 안에만 저장되며, 개발자의 서버로 전송되지 않습니다.

1. 저장·처리하는 정보

정보저장 위치목적
출장·업체·방문 기록(질문, 답변 텍스트, 메모)기기 내 (앱 데이터베이스)방문 기록 관리
음성 녹음기기 내답변 기록, AI 전사·번역·요약
사진(부스·명함·제품)기기 내방문 기록 첨부
(선택) 이용자가 직접 입력한 OpenAI API 키기기 내 보안 저장소(iOS 키체인)아래 3항의 고품질 AI 처리

앱은 위치정보, 연락처, 광고 식별자를 수집하지 않으며, 광고·추적 SDK를 사용하지 않습니다.

오프라인 준비 시 번역·음성인식 모델 파일을 Google(ML Kit)·Hugging Face 서버에서 내려받습니다. 이는 프로그램 파일을 받는 일방향 다운로드이며, 이용자의 기록은 전송되지 않습니다.

2. 기기 권한

  • 마이크: 상대방 답변 녹음
  • 카메라: 부스·명함·제품 사진 촬영
  • 사진 보관함: 사진 첨부(읽기) 및 촬영한 사진 저장(추가)
  • 음성 인식: 기기 안에서 녹음을 글자로 변환 (기기 내 처리, 외부 전송 없음)

권한은 해당 기능을 처음 사용할 때 요청되며, 거부해도 나머지 기능은 사용할 수 있습니다.

3. 선택적 AI 처리 (이용자 본인의 API 키)

기본 상태에서 전사·번역은 모두 기기 안에서 처리되며 데이터가 기기를 떠나지 않습니다.

이용자가 설정에서 본인의 OpenAI API 키를 입력한 경우에만, 답변 녹음 파일이 암호화된 통신(HTTPS)으로 OpenAI(미국)에 전송되어 텍스트 변환(전사)·번역·요약 처리됩니다. 처리 결과는 앱으로 반환되어 기기에 저장되며, 전송은 이용자와 OpenAI 간의 API 이용계약에 따라 이루어지고 해당 API는 입력 데이터를 AI 학습에 사용하지 않습니다. 키를 삭제하면 이후 처리는 다시 기기 안에서만 이루어집니다.

4. 보관 및 파기

  • 모든 기록은 기기에만 보관됩니다. 이용자가 앱 안에서 기록을 삭제하거나 앱을 삭제하면 즉시 파기됩니다.
  • 개발자는 이용자의 데이터를 보관하는 서버를 운영하지 않습니다.

5. 이용자의 권리

이용자는 언제든지 자신의 기록을 앱 안에서 열람·수정·삭제할 수 있습니다.

6. 아동의 개인정보

본 앱은 만 14세 미만 아동을 대상으로 하지 않습니다.

7. 방침의 변경

방침이 변경되면 앱 또는 스토어 페이지를 통해 고지하며, 본 문서의 시행일을 갱신합니다.
